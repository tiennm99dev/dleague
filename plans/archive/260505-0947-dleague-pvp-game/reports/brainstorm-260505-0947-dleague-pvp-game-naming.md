# Brainstorm: PvP -dle Game Naming

**Date:** 2026-05-05
**Final Pick:** **Dleague**
**Status:** Name locked in, pre-implementation

---

## Problem Statement

User building new PvP variant of -dle games (Wordle/LoLdle style) with player-vs-player mechanics. Needs brandable name for mainstream casual audience.

## Initial User Ideas (Rejected)

| Idea | Verdict | Reason |
|------|---------|--------|
| Worldle | REJECT | Already taken — popular geography -dle game (worldle.teuteuf.fr). Major SEO/trademark/user-confusion risk. |
| PvPdle | REJECT | Awkward pronunciation, "PvP" is gamer jargon limiting mainstream reach, reads as hashtag not brand. |

## Direction Chosen

- **Theme:** Competitive/league framing
- **Audience:** Mainstream casual (no gamer jargon, must pass phone-pronunciation test)

## Candidates Evaluated (14 total)

**Battle/Duel:** Battledle, Duedle, Versusdle, Clashdle, Rivaldle
**Arena/League:** Dleague, Arendle, Dlympics, Dlash
**Multiplayer:** Dueldle, Squadle, Co-dle
**Meta/World:** Dleverse, Dlehub

## Top 3 Refined (League-themed, mainstream)

1. **Dleague** — "dee-leeg" — reads as "the league", universal sports word, brandable
2. **Champdle** — "champ-dull" — "champion" is mainstream, very brandable
3. **Matchdle** — "match-dull" — clearest function, zero explanation needed

## Final Recommendation: Dleague

### Rationale
- **Mainstream:** "league" exists in NFL, MLB, Premier League, Little League — universal
- **Pronounceable:** passes phone test
- **Expansion-friendly:** Dleague Pro / Dleague Daily / Dleague Cup all work
- **Brandable:** stylized "D" prefix gives strong logo direction
- **Clean pronunciation** on first read

### Trade-offs
- Minor SEO overlap with NBA D-League (rebranded to G League in 2017, mostly faded)
- Generic enough that brand identity must come from logo + product, not name alone

## Pre-Launch Checklist

- [ ] Check domain availability: dleague.com, dleague.io, dleague.gg, dleague.app
- [ ] USPTO/EUIPO trademark search for "Dleague"
- [ ] Social handle availability: @dleague on X, Instagram, TikTok, YouTube
- [ ] Confirm no NBA D-League trademark conflict (likely fine post-rebrand, verify)
- [ ] Lock in tagline direction (e.g., "Where -dle goes pro")

## Risks

| Risk | Severity | Mitigation |
|------|----------|------------|
| Domain .com taken | Med | Fall back to .gg or .io (gaming-friendly TLDs) |
| NBA trademark dispute | Low | Different sector (puzzle games vs basketball); verify with quick TM search |
| Mainstream confusion with sports leagues | Low | Logo + UI immediately signal puzzle game context |

## Next Steps

1. Domain + trademark + social handle check (homework before commit)
2. If clean: lock name, design logo direction
3. If conflicts: fall back to **Champdle** (#2 pick) or **Matchdle** (#3)
4. Begin product design — game mechanics, ranked system, matchmaking

## Unresolved Questions

- Will product include ranked ladder, or just casual head-to-head?
- Synchronous real-time PvP or async (turn-based, daily challenges)?
- Single -dle game type at launch, or platform hosting multiple -dle variants?
- Monetization model — ads, premium, cosmetics, tournament entry?
